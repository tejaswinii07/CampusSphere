DBMS Features Used

The examination module demonstrates several database concepts used in CampusSphere.


  • Foreign Keys connect examinations with courses.
  • Foreign Keys connect results with students, courses and exams.
  • Unique Constraints prevent duplicate exam registrations.
  • Trigger automatically calculates result grades.
  • Stored Procedures provide reusable academic queries.
  • Views provide combined academic information.
