CampusSphere Advanced DBMS Module

This module demonstrates how a real-world campus management system can use advanced database features such as views, stored procedures, stored functions, triggers, indexes and transactions. These features reduce application-level duplication, improve data integrity and demonstrate the capabilities of MySQL.

Stored Functions

CalculateAttendance()

Calculates attendance percentage from the total number of classes and classes attended.


SELECT CalculateAttendance(40, 36);

CalculateGrade()

Converts marks into the corresponding academic grade.


SELECT CalculateGrade(88);

Database Triggers

before_attendance_insert -------------------------------- Automatically calculates attendance_percentage before a new attendance record is inserted. before_result_insert -------------------- Automatically calculates the grade from marks before a result record is inserted. equipment_maintenance_trigger ----------------------------- Automatically creates a maintenance record when equipment status changes to "Under Maintenance".

Transaction Management

CampusSphere demonstrates transaction handling using room booking operations. COMMIT permanently saves successful operations, while ROLLBACK cancels uncommitted changes.


START TRANSACTION; INSERT INTO room_bookings (...); COMMIT; -- or ROLLBACK;

Relational Database Design

CampusSphere separates data into related entities such as students, faculty, courses, departments, attendance, examinations, placements, rooms and complaints.


  • Primary Keys uniquely identify records.
  • Foreign Keys establish relationships between tables.
  • Unique Constraints prevent duplicate values where required.
  • Normalization reduces unnecessary data duplication.
  • Views simplify complex multi-table queries.
  • Indexes improve query performance.
  • Triggers and Functions automate database-level operations.
  • Stored Procedures encapsulate reusable database logic.
